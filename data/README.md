# 📂 Datos

Acá está el archivo **`comercio_electronico.zip`**, que contiene `comercio_electronico.csv` (≈ 43 MB sin comprimir, 536.350 filas y 8 columnas). Se comprimió para poder subirlo desde la web de GitHub; **pandas lo lee directamente**, sin descomprimirlo.

| Columna | Qué representa |
|---|---|
| `TransactionNo` | Número de compra (si empieza con `C`, es una cancelación) |
| `Date` | Fecha de la compra (formato `mes/día/año`) |
| `ProductNo` | Código del producto |
| `ProductName` | Nombre del producto |
| `Price` | Precio unitario |
| `Quantity` | Cantidad comprada |
| `CustomerNo` | Número de cliente |
| `Country` | País del cliente |
